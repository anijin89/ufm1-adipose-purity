# Purity bias masquerades as an adiposity signal in purified human adipocytes

Reproducible analysis code and per-figure/per-table source data for the manuscript
*"Purity bias masquerades as an adiposity signal in purified human adipocytes, while
adipose-tissue UFM1 tracks eIF2α/PERK-dependent ER stress and the UFMylation imbalance
index normalises after bariatric surgery: a multi-cohort transcriptomic study."*

This is a **pure re-analysis study**: no new samples were generated. Every dataset analysed
is publicly available (GEO / eQTL Catalogue, listed below), and every number reported in the
manuscript's main and supplementary tables and figures is produced by the scripts in `code/`
and reproduced in `source_data/`.

---

## Repository layout

```
.
├── README.md
├── LICENSE
├── .gitignore
├── code/            # 36 numbered analysis scripts (run 01 → 34 in order) + requirements.txt
└── source_data/     # 18 CSV/TSV files: the exact values behind every figure and table
```

The `code/` scripts read **raw** inputs from a local `data/` directory and write intermediate
outputs to `results/` and figures to `figures/`. Those directories are intentionally **not**
committed: `data/` holds ~2 GB of public GEO matrices (redownloadable by accession, see below),
and `results/` are fully regenerated by running the pipeline. The committed `source_data/`
contains the curated, rounded-to-manuscript values so that each reported number can be verified
directly without re-running anything.

## How to reproduce

1. **Create the environment** (Python 3.13):

   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install -r code/requirements.txt
   ```

2. **Place raw inputs** in a sibling `data/` directory (relative to where you run the scripts),
   named exactly as the scripts expect. All are downloads from the public accessions listed
   under *Data provenance*:

   | File | Source |
   |---|---|
   | `GSE70353_series_matrix.txt.gz`, `GSE70353_clinical.csv` | GSE70353 |
   | `GSE174475_expr.txt.gz` | GSE174475 |
   | `GSE245948_cpm.csv.gz` | GSE245948 |
   | `GSE59034_series_matrix.txt.gz` | GSE59034 |
   | `GSE176171_barcodes.tsv.gz`, `GSE176171_features.tsv.gz`, `GSE176171_cell_metadata.tsv.gz` | GSE176171 (single-nucleus) |
   | `GPL10558_probe2gene.tsv`, `GPL11532_probe2gene.tsv`, `GPL13667_probe2gene.tsv`, `GPL16686_probe2gene.tsv` | GEO platform annotations |
   | `Homo_sapiens.gene_info.gz` | NCBI Gene |
   | `QTD000116.all.tsv.gz(.tbi)` | eQTL Catalogue (GTEx V8 subcutaneous adipose) |

3. **Run the pipeline** in numerical order from the `code/` directory:

   ```bash
   cd code
   for f in $(ls *.py | sort -V); do echo "== $f"; python3 "$f" || break; done
   ```

   Early scripts (01–05) parse GEO matrices and build probe→gene annotation. The analysis
   stage (06–13) computes co-expression, enrichment, single-nucleus pseudobulk, lasso/ROC and
   the axis-score models. Figure scripts (14–34) render the manuscript figures and regenerate
   the source-data tables, including the purity-sensitivity (32), index-construction (33) and
   GSE245948 progressive-adjustment (34) analyses that underpin Table 2 and Supplementary
   Table S10.

4. **Verify** the regenerated `source_data/` values against the committed CSVs.

## Source data files

`source_data/` holds the exact per-table / per-figure values reported in the manuscript:

- **Table 2 (ER/eIF2α coupling)** — reconstructed from `TableS3b`, `TableS3c`, `TableS3d` and
  `TableS10a` (the GSE245948 column carries crude + fully-adjusted values from script 34).
- **Supplementary Table S10 (sensitivity)** — `TableS10a` (GSE245948 progressive adjustment),
  `TableS10b` (GSE53376 index construction), `TableS10c` (GSE174475 purity sensitivity),
  `TableS10d` (GSE174475 progressive adjustment).
- **Paired interventional estimates** — `TableS4a/b/c` (per-cohort paired tests),
  `TableS5` (pooled estimates and heterogeneity).
- **Purity artefact** — `TableS7` (crude vs adjusted), `TableS1` (single-nucleus participant
  reconstruction).
- **Enrichment** — `TableS2a/S2b` (positive/negative modules).
- **Phenotype anchoring & negative findings** — `TableS6` (surgical response),
  `TableS8` (GSE53376 qPCR concordance), `TableS9` (GTEx *UFM1* cis-eQTL).

## Software

All analyses are in Python. Key libraries: pandas, numpy, scipy, statsmodels, scikit-learn,
matplotlib, gseapy (full pinned versions in `code/requirements.txt`). Ensembl gene identifiers
used in the scripts were verified against Ensembl `xrefs/symbol` and mygene (species = *Homo
sapiens*).
